# V716 — Responsive song-source links

- Display song-source URLs without the `http://` or `https://` scheme and optional `www.` prefix. The link still opens the original full URL, which remains available as its title.
- Wrap long URLs at any character instead of letting an unbroken address widen the details grid.
- In narrow and portrait layouts, cap the URL column beside the track path and let status bubbles span the full row below, preventing the source link from squeezing them.
