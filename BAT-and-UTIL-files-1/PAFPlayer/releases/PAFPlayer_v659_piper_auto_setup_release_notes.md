# PAFPlayer V659 — automatic Piper setup

When the DJ needs local speech and Piper or its voice is missing, it creates a separate private environment, downloads Piper and the en_US-lessac-medium voice, and verifies actual speech synthesis. It keeps existing installations, user-selected executable and voice paths, and incomplete attempts. Setup runs in the background; failure leaves generated text visible in Help and does not stop music. The default model download is about 63.2 MB plus Piper and dependencies.

Python 3.10 on Windows uses ONNX Runtime 1.19.0, because the newer version failed to load on the test machine. Private Piper setup completed and verified its own speech file. A live Ollama-to-Piper test generated six WAV files in 53.5 seconds; FFplay played the setup WAV with volume muted and exited successfully. Four setup tests, three Help tests, 22 existing DJ tests, and seven command tests passed. All 28 bundled modules compiled, and the release matches the active player. [Test report](../tests/reports/v659-piper-auto-setup-checks-20261111.json). OpenAI credentials tested on this machine returned HTTP 401. The editable DJ module matches its single-file bundle; no literal C:\BAT files were changed.
