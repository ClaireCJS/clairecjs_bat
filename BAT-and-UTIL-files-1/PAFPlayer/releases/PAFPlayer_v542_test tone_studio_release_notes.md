# PAFPlayer V542 — Test Tone studio

Released October 14, 2026.

## Added

- A Test Tone editor inside Speaker Expansion Matrix using the selected native
  output device, channel layout, sample rate, and bit depth.
- Five patterns and independently editable frequency, pattern, and volume for
  an unbounded list of simultaneous tones.
- `Ctrl+T`, held arrows/mouse buttons, middle-click/`Shift+T`, and
  triple-click/`Alt+T`/`Ctrl+Alt+T` controls.
- Named tone-set persistence with `Ctrl+S`/`Ctrl+L` and matching web controls.
