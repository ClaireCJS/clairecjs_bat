# PAFPlayer V508 — lock-screen companion installer

V508 adds `lockscreen/lockscreen_installer.py` and `PAFPlayer_v508_lockscreen_install_bundle.zip` for Windows 10 x64. This release bumps the player version to V508 without changing playback behavior. The bundle includes the existing signed V505 companion, its public certificate and three x64 Debug runtime dependencies. It can be copied to a second Windows 10 computer and extracted without the project build tree.

The installer checks Windows version and architecture, validates SHA-256 hashes, package identity and lock-screen manifest, and compares the MSIX signer with the pinned certificate. It checks registration in the invoking user's account. When trust is missing, it explains the self-signed certificate and requests an explicit yes before launching a narrow UAC elevation to add it to `LocalMachine\\TrustedPeople`. The original unelevated process then registers the MSIX and dependencies in that same user account and verifies the reported package version. `--check` validates and reports registration without making changes. If consent, UAC, validation or registration fails, it stops with an error rather than claiming success.

After registration, the installer tells the user to launch **PAFPlayer Lock Screen**, configure the official player's `host:port`, and select it under **Settings → Personalization → Lock screen → Choose one app to show detailed status**. Windows will not select the slot on the user's behalf. The locked display can show title, artist, playback state and lyric text, but the background task can be delayed by Windows; it is not a live lyric surface or album-art display.

The old `Register.ps1` and two incomplete PowerShell snippets were archived under `lockscreen/archive/legacy-installers/`. The superseded first V505 MSIX was archived under `lockscreen/archive/packages/`. Old V505 build outputs and root-level lock-screen replacement backups were moved under `lockscreen/archive/` after the distributable dependencies were copied and hash-verified. Historical release copies were preserved. No files were permanently deleted.

Validation: eight installer regression tests passed, the two existing V505 package tests passed, and Python compilation checks passed. The portable bundle was opened and its member hashes checked against the active distribution. Certificate trust, AppX registration in the interactive user's account and actual appearance in the Windows picker remain unverified here: prior automatic approval review rejected the certificate trust change, and this session's shell is a separate sandbox user. No `C:\\BAT` files were changed.
