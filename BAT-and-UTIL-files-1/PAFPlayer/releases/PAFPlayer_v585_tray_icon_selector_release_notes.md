# PAFPlayer V585 — compact tray-icon selector

The web configuration no longer presents all 200 tray-icon combinations as a
large gallery. It now has two compact, wrapping button groups:

- **Button type** contains the twenty icon motifs.
- **Color** contains the ten available colors.

The active button in each group is highlighted. Choosing either option applies
the corresponding type/color combination immediately, and the type previews
redraw using the selected color.
