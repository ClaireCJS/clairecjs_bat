# PAFPlayer V557 — scoped J and QQ song dialogs

- J opens the standard song-selection dialog using only the active playlist.
- QQ opens the identical dialog using the broad known-library catalog, including
  `everything.m3u`, the fallback song list, and live music-root reconciliation.
- Choosing an existing playlist member queues it next; choosing a new library
  song from QQ adds it to the playlist and queues it next.
