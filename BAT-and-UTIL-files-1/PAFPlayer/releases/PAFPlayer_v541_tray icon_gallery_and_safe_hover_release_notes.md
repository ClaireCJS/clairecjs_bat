# PAFPlayer V541 — Tray icon gallery and safe hover

Released October 14, 2026.

## Changed

- Web Config offers 20 persistent, previewed tray-icon designs.
- The native right-click menu includes the same checked icon chooser.
- Icon changes apply to the live notification-area icon without a restart.
- The artwork hover waits 700 ms, stays outside the icon rectangle, and is
  click-through so it cannot obstruct right-clicking.
