# PAFPlayer V763 — circled-number lyric spacing

Windows Terminal karaoke no longer inserts two extra cells after bold circled-number substitutions ❶–❿. The original lyric spacing is kept, so the next sung word appears at the intended distance. Adjacent enclosed-number glyphs remain adjacent except for whitespace already present in the source text. The unrelated pen-glyph safety cell is unchanged.
