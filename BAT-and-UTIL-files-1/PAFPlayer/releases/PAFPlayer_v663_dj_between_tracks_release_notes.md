# PAFPlayer V663 — automatic DJ commentary between tracks

Automatically prepared commentary that finishes during a song waits until the next track begins. The ready status says “Ready for next song.” `#djforce` remains an explicit immediate interruption. Track transport and modal Help behavior remain unchanged. V662 adds OpenRouter/Gemini text fallbacks and the OpenAI credit warning. A browser probe verified that Warnings is the last tab and displays the credit warning; a real local Ollama/Piper run after simulated OpenAI credit exhaustion generated six WAVs. The first run exceeded the former 120-second limit, so the local timeout was raised to 600 seconds. The hosted free providers have not been verified live because their API keys are not configured.
