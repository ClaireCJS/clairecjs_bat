# PAFPlayer V504 — options on each tray computer

- The official tray and each `--tray-only HOST:PORT` client offer **Live lyrics in tooltip** and **Album art desktop wallpaper** in their context menus. Both are off by default and are saved for the current Windows user on that computer in `HKCU\Software\ClaireCJS\PAFPlayer\TrayMachine`. They do not change the player's saved `TrayIconEnabled` preference or any server setting.
- The lyric option uses the official owner's live lyric status. Remote clients poll approximately every 0.4 seconds when enabled; the Windows tooltip is limited to 127 characters and shell redraw timing varies.
- The wallpaper option requests the current owner's artwork with an owner identity and artwork-generation check. The server renders a centered desktop-sized BMP, so a tray-only client needs no image library. A local worker applies it through the Windows desktop wallpaper API without blocking playback or tray clicks.
- The prior picture path is restored when the option is disabled, the track or connection is lost, or the tray exits normally, provided the user has not selected a different wallpaper meanwhile. A named mutex prevents two PAFPlayer trays on one desktop from competing for the background. A crash can leave the artwork in place until the tray restarts or the user changes it. Windows slideshow/theme mode and per-monitor choices are not restored.
- This is desktop background control, not Windows 10 lock-screen background control. PAFPlayer's experimental SMTC bridge is separate from the Windows Lock screen Settings app-status picker; the player is not registered as a detailed-status app there.
- The existing triple-click, double-click, delayed menu, `--tray`/`--no-tray`, official-instance ownership, `--instance` handoff, native tag viewer, and remote command routing remain in place. Remote wallpaper requires a V504 or newer player server.
