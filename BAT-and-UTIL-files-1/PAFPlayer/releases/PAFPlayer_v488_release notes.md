# PAFPlayer V488 — Console volume entry

- Capital `V` (`Shift+V`) now opens a volume-entry prompt during active or paused playback.
- Numeric entries accept 0–400%; Up/Down adjust by 20 points, `=` restores 100%, and `P` restores the value before the last adjustment.
- Lowercase `v` continues to advance the visualizer mode.
- Volume-entry parsing and key routing have built-in regression coverage.
