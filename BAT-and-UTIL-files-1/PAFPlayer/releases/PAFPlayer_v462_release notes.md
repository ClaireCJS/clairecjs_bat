# PAFPlayer V462 — Web controls and tags

- Tags are now their own final web-config tab and section, expanded by default.
- Every applicable Fav/Def dropdown, including Web Karaoke, now has a `↻` control:
  click cycles favorites, right-click cycles all values, and triple-click restores
  the default. Dropdown options keep the default first, then saved favorites.
- Artwork Pop-up and Floating Lyrics controls use the same ordering. `Bring to Top`
  stays clickable when Always On Top is active, but is visually dimmed to show it
  is redundant.
- The existing album-art gesture tooltip was retained and verified: it describes
  click, right-click, double-click, and triple-click/default-viewer behavior.
- Removed these completed items from both active TODO copies.
