# PAFPlayer V540 — Web choices and Discord help

Released October 14, 2026.

## Changed

- Playback Device favorites/defaults preserve the complete selected output mask.
- Bar artwork blend now has favorite/default controls and persistent selection.
- Auto-set to tallest is accepted by the web action validator and works live.
- Floating Lyrics uses a 🌐 Web Config shortcut with an explanatory tooltip.
- Discord has a standalone local setup page opened by **Help**.
- Discord documentation now explains that webhooks post to channels and cannot
  create Discord user-profile activity; Rich Presence would require a different
  integration.
