# PAFPlayer V551 — tray icon matrix and full hover

- Provides 20 distinct tray icon types × 10 colors = 200 combinations.
- Groups the native picker by icon type and then color.
- Preserves every saved index through periodic tray refreshes.
- Adds a persistent, checkable **Full info on tooltip** command.
- Shows the existing album-art/details card after a deliberate 0.666-second hover.

The detailed hover remains click-through and is disabled by default.
