# PAFPlayer V490 — Floating teeny solutions

- Floating Lyrics can show small textual Emojimaxx solutions beneath substituted emoji, matching Web Karaoke.
- A persisted **Teeny answers** toggle is available from the floating edit title bar and context menu.
