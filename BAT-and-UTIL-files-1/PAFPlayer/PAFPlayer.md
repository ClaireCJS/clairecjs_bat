# PAFPlayer

PAFPlayer is a Windows music player with a console visualizer, synchronized
lyrics, artwork, playback controls, a web configuration page, and optional
tray, remote-control, screensaver, and lock-screen integrations. When feasible,
it buffers the playing audio file in memory so its original file can be renamed
or removed without interrupting the decoder.

Run `python PAFPlayer.py` from this folder. The player bundles its own
feature modules; optional integrations may need additional Windows or audio
tools.
